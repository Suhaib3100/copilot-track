# Copilot Analytics Dashboard

A Next.js web application that displays GitHub Copilot usage metrics for your organization.

![Dashboard Preview](https://via.placeholder.com/800x400?text=Copilot+Analytics+Dashboard)

## Features

- 📊 **Summary Cards**: View total active users, prompts, generations, acceptances, and lines of code added
- 📈 **Interactive Charts**: 
  - Bar chart showing top 10 users by prompts
  - Line chart showing daily prompts across the organization
  - Bar chart showing lines of code added per user
- 📋 **Sortable Users Table**: View all users with their metrics, sortable by any column
- 📅 **Date Filtering**: Filter data within the 28-day reporting window
- 🌓 **Dark Mode Support**: Automatic theme based on system preferences

## Prerequisites

- Node.js 18.x or later
- A GitHub Personal Access Token (PAT) with:
  - `read:org` scope
  - "Organization Copilot metrics (read)" permission
- Copilot usage metrics policy enabled for your organization

## Setup

### 1. Clone the Repository

```bash
cd copilot-track
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env.local` file in the project root:

```bash
# Copy from example
cp .env.example .env.local
```

Edit `.env.local` with your values:

```env
# GitHub Personal Access Token with read:org scope and "Organization Copilot metrics (read)" permission
GITHUB_TOKEN=ghp_your_token_here

# Your GitHub organization slug (name)
ORG_SLUG=your-org-name
```

### 4. Run Development Server

```bash
npm run dev
```

### 5. Open the Dashboard

Navigate to [http://localhost:3000/copilot-dashboard](http://localhost:3000/copilot-dashboard)

## API Endpoints

### `GET /api/copilot-metrics`

Fetches and aggregates Copilot usage metrics from GitHub.

**Response:**

```typescript
{
  success: boolean;
  users: {
    login: string;
    totalPrompts: number;
    totalGenerations: number;
    totalAcceptances: number;
    totalLocAdded: number;
    days: {
      day: string;      // YYYY-MM-DD
      prompts: number;
      generations: number;
      acceptances: number;
      locAdded: number;
    }[];
  }[];
  reportStartDay?: string;  // YYYY-MM-DD
  reportEndDay?: string;    // YYYY-MM-DD
  error?: string;
}
```

## Metrics Explained

| Metric | Description |
|--------|-------------|
| **Prompts** | User-initiated interactions with Copilot (explicit prompts sent) |
| **Generations** | Code suggestions/completions generated by Copilot |
| **Acceptances** | Suggestions accepted by users (apply, insert, copy) |
| **LOC Added** | Lines of code added to the editor from Copilot |

## GitHub API Reference

This dashboard uses the following GitHub API endpoints:

- `GET /orgs/{org}/copilot/metrics/reports/users-28-day/latest` - Returns download links for NDJSON files containing user-level metrics

For more information, see:
- [GitHub Copilot Usage Metrics API](https://docs.github.com/en/enterprise-cloud@latest/rest/copilot/copilot-usage-metrics)
- [Copilot Metrics Concepts](https://docs.github.com/en/copilot/concepts/copilot-metrics)
- [Data Available in Copilot Usage Metrics](https://docs.github.com/en/copilot/reference/copilot-usage-metrics/copilot-usage-metrics)

## Troubleshooting

### "GITHUB_TOKEN is not set" Error

Ensure your `.env.local` file exists and contains a valid `GITHUB_TOKEN`.

### "ORG_SLUG is not set" Error

Ensure your `.env.local` file contains your organization name as `ORG_SLUG`.

### 403 Forbidden Error

- Verify your PAT has the `read:org` scope
- Verify your PAT has "Organization Copilot metrics (read)" permission
- Verify the "Copilot usage metrics" policy is enabled for your organization

### No Data Showing

- Data may take up to 3 days to appear after Copilot usage
- Ensure users have telemetry enabled in their IDEs
- Check if the date range filter is set correctly
